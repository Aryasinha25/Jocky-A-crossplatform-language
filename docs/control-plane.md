# Control Plane

The Phase 5 Go Control Plane serves as the central hub for storing, organizing, and querying forensic metadata generated by JOCKY endpoints.

It exposes a RESTful API powered by Go and PostgreSQL, completely detached from the Rust forensic execution environment.

## Endpoint Lifecycle
Endpoints must register themselves before pushing data. The control plane tracks them using generated UUIDs, ensuring that investigation data cannot be spoofed across different identities.
