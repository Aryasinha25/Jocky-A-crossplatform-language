# Analyst Workflow

The JOCKY Analyst Console is designed to support the standard forensic response lifecycle:

1. **Dashboard Triage**: View macro statistics across the entire environment. Spikes in critical findings immediately indicate an incident.
2. **Endpoint Isolation**: Locate the offending endpoint from the Endpoints inventory. Check its last heartbeat.
3. **Investigation Dive**: Select the investigation payload generated by the JOCKY Rust Runtime. Review the overall `RiskScore`.
4. **Chronological Analysis**: Inspect the Investigation Timeline to establish a sequential map of events.
5. **Topological Mapping**: Pivot to the Investigation Graph to trace process injection trees, network connections, and the evidence artifacts underlying specific findings.
