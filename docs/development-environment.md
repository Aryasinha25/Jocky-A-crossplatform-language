# Development Environment

To build and run JOCKY, the following tools are required:
- Rust & Cargo (rustup)
- Go 1.21+
- Node.js v24+
- npm v11+
- Docker & Docker Compose

## Setup Instructions
1. Install Rust via rustup.
2. Install Go from golang.org.
3. Install Docker Desktop.
4. Install Node.js.
